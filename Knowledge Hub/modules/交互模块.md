# 交互模块

## 组件关系

```text
InteractSearcher（交互者）
    -> Physics.OverlapSphere
    -> Interactable（目标）
    -> InteractOption（池化 UI 选项）
```

## Interactable

给可交互目标挂 `Interactable` 或其业务子类。Inspector 配置：

- 提示文本；
- 图标；
- `UnityEvent` 交互回调。

可重写：

```csharp
public override bool CanInteract(GameObject interactor)
{
    return true;
}

protected override void OnInteracted(GameObject interactor)
{
    // 业务后续逻辑。
}
```

`CanInteract` 在 Searcher 扫描时被调用，应快速、无分配、不修改目标状态。

## InteractSearcher

给玩家或交互发起者挂 `InteractSearcher`，配置：

- 搜索半径和间隔；
- 物理层；
- `InteractOption` 预制体和 UI 根节点；
- 选项纵向间距；
- 交互按键（当前默认 `F`）。

Searcher 会周期性范围检测，用目标的 InstanceID 管理选项去重，并通过对象池生成或回收选项。它使用滚轮、上下方向键切换选项，以 F 执行当前选项。

### 当前链路注意事项

`InteractOption.Bind` 注入的是 `Interactable.OnInteractEvent`。因此 `ExecuteInteract` 当前触发 UnityEvent，而不会自动调用 `Interactable.Interact(interactor)`，也就不会自动传入交互者并调用子类的 `OnInteracted`。

业务需要调用 `OnInteracted` 时，应明确规划交互回调：例如 UnityEvent 指向一个业务桥接方法，由桥接方法再调用 `Interactable.Interact(interactor)`；或在后续有明确需求时重构 Option 持有 `Interactable` 与 interactor。不要假定当前实现已自动完成这一步。

## 扩展边界

- 改检测形状时重写 `CollectInteractables`，不要重写整个 Update。
- 改选择方式时重写 `HandleSelectionInput`。
- 改 UI 表现时继承 `InteractOption`，重写 `Bind`、`SetSelected`、`PlayClick`。
- 不把战斗、任务、背包或对话逻辑写进通用 `Interactable`；通过 UnityEvent 或业务子类接入。
