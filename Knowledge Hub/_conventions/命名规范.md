# 命名规范

## 接口

- 前缀 `I`：`IDataProvider`、`IInputReader`、`IBlackboardData`、`IInteractable`
- 方法命名：动词开头，`Tick()`、`Execute()`、`ConsumePressed()`

## 抽象基类

- `Base` 结尾：`BaseInputProvider`、`UnitDriverBase`
- 或直接描述性命名：`MovementStrategy`、`BlackboardAttribute<T>`

## 具体类

- `{Entity}DataProvider`：`PlayerDataProvider`、`EnemyDataProvider`
- `{Name}Attribute`：`MoveAttribute`、`JumpAttribute`、`InteractAttribute`
- `{Function}System` 或 `{Function}Manager`：`QuestManager`、`DialogueSystem`、`AudioManager`

## 命名空间

- 框架代码统一 `CoreFramework`
- 编辑器代码 `CoreFrameworkEditor`

## Key/常量

- 属性 Key：`public const string KEY = "Move"` 定义在属性类自身
- 事件名：集中在 `EventNames.cs` / `GameplayEventNames.cs`

## 文件组织

```
Core/
├── Gear/           — 基础工具（EventSystem, ObjectPool, AudioManager...）
├── Input/          — 数据源处理（待迁移为 DataProvider/）
├── Expand Component/ — 可挂载组件（UnitMover...）
├── Interaction/    — 交互系统
├── Lite Framework/ — 轻量子系统（HSM, Quest...）
└── BehaviorCore/   — 行为与动画系统
Gameplay/
└── Core/           — 玩法层核心抽象
```
