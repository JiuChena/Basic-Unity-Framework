# BehaviorEditor 轨道脚本生成器

- 新增菜单 Tools/Behavior Editor/Create New Track Scripts，用于生成新 BehaviorEditor 轨道的最小五文件结构。
- 生成器记录用户最后使用的父文件夹到 EditorPrefs，下次打开窗口自动恢复；也支持输入 Unity 资产路径或通过文件夹选择器选择当前项目 Assets 下的已有文件夹。
- 输入 Track Name 后，工具会创建独立的 {TrackName}Track 文件夹，生成 BehaviorTimeline{TrackName}Track、BehaviorTimeline{TrackName}ClipAsset、{TrackName}TrackData、{TrackName}TrackExecutor 和 {TrackName}TimelineTrackCompiler。
- 编译器带有 BehaviorTrackCompiler 特性，依靠现有 TypeCache 自动发现，不修改 BehaviorExecutor、BehaviorClip、窗口导出分发或中央注册表。
- 模板中的运行时数据使用片段起始时间、持续时间和一个示例 value 参数；执行器保留 Begin/Tick/Stop 生命周期位置，开发者应在生成后替换为实际轨道逻辑。
- 工具拒绝非法 C# 类型名、Assets 外路径和已存在的输出文件，不覆盖已有脚本。需要复杂数据定义、导出汇总、业务执行 SO、作者期预览或 Gizmo 时，再在对应轨道目录按需增加脚本。
- 修正空路径回退逻辑：运行时目录回退到运行时默认路径，Editor 目录回退到 Editor 默认路径，避免清空 Editor 路径后误判为运行时目录。
