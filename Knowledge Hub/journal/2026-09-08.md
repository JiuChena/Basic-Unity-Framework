# BetterHSM 接入 GAS 顶层骨架

- 建立 `BetterHSMAbilitySO` 的两级选择骨架：顶层实体分类为 `Character`、`Enemy`、`NPC`，第二层为状态图注册方案枚举；具体角色和敌人方案暂不提前定义。
- 建立静态固定嵌套目录：顶层分类枚举 -> 注册方案枚举 -> `Func<AbilityOwnerContext, BetterHSMAbilityContext>` 工厂方法；不提供动态注册、反射扫描或运行时增删映射。
- 建立 `BetterHSMAbilityContext` 泛型包装，使具体注册方案可以创建并返回实体独有的状态上下文和 `BetterHSM<TContext>`，GAS Runtime 无需知道具体泛型类型。
- `BetterHSMAbilityRuntime` 在 `AbilityInit` 创建状态图，在 `AbilityUpdate` 唯一驱动，在 `AbilityDispose` 释放；运行时数据向其他能力公开状态查询入口。
- 当前未连接 Unity Pipeline，尚未完成 Unity Editor 编译验证；已完成源码引用、旧入口残留和 `git diff --check` 检查。
- 新增 `Character + CH0221Test` 最小状态图方案：仅根据 `InputRuntimeData.Move` 在 Idle 与 Move 状态间切换，用于验证 BetterHSM 通过 GAS 能力创建和驱动的完整链路。
