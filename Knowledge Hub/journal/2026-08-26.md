# 2026-08-26 能力系统职责收紧

## 完成

- `AbilityComponent` 改为纯能力装配与 Unity 生命周期转发器，不再要求、获取或接管 `Rigidbody`、`CapsuleCollider`、物理查询和速度提交。
- `AbilityContext` 收紧为 `Owner`、`Transform` 与共享 `Blackboard`，移除移动状态字段和类型服务容器。
- `MovementAbilityRuntime` 成为移动领域组合根：自行解析或补齐物理组件，创建刚体适配器、浮动形状、接地、悬浮、重力、跳跃、陡坡和边缘保护纯 C# 模块，并独占提交最终速度。
- 浮动胶囊配置迁入 `MovementAbilitySO`，恢复“形状同步 -> 接地距离 -> 悬浮修正 -> 速度提交”的完整闭环。
- 跳跃和边缘保护配置一并迁入移动资产，移除仅依赖 Context 服务容器协作的三份旧能力资产与 Runtime。
- `Preload` 场景中的 Player 能力列表调整为输入监听、移动两项；原测试参数已迁移至 `MovementAbility.asset`。

## 验证待办

- 受本轮“不使用 Unity CLI”约束，仅完成静态引用与编译风险检查；需在 Unity 主编辑器刷新脚本后确认 Console 为零编译错误，并验证浮动胶囊、跳跃和边缘保护手感。
