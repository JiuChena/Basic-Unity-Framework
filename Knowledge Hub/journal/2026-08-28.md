# 能力脚本生成工具

- 新增 `Tool/GAS/Create New Ability Scripts` 菜单，用于在 Project 窗口选中的 `Assets` 文件夹下创建能力子目录。
- 工具生成 `{AbilityName}AbilitySO`、`{AbilityName}AbilityRuntimeData` 和 `{AbilityName}AbilityRuntime` 三份脚本，并提供当前能力生命周期的 override 模板。
- 修复生成器模板中逐字字符串嵌套双引号未转义的问题，该问题会导致 `AbilityScriptCreatorWindow.Templates.cs` 在 Editor 程序集编译时出现连续语法错误。
- 生成的 Runtime 在 `AbilityInit` 创建并注册 RuntimeData，在 `AbilityDispose` 按实例注销；生成器同时将能力名称写入 `AbilityRuntimeDataType` 的受控自动生成区域。
- 生成器会在写入前检查 RuntimeData 键的冲突和自动生成标记；能力配置资产仍需手动添加到目标 `GameplayAbilitySystem` 列表。
- 使用 Unity 2022.3 Roslyn 编译器对 Editor 程序集做临时编译检查通过，未修改 Unity CLI 或项目受保护配置文件。
- 简化输入能力配置：移动动作和按钮映射改用 `InputActionReference` 直接引用 Input Actions 动作，旧动作地图名和动作名仅作为隐藏迁移回退值。
- 输入能力 Runtime 在初始化阶段解析并缓存动作，运行帧继续只负责采集输入并写入 `InputRuntimeData`，不改变 GAS 的定义资产、运行时实例和拥有者上下文职责。
