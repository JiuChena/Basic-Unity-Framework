# 2026-08-16 GTS 头发高光贴图验证

- 直接拆分并统计 `CH0221_Hair_Spec.png`，确认 RGB 的 `2 * RGB - 1` 为近单位向量编码；撤销“不是单位法线/三方向响应图”的旧判断。
- 试验将 RGB 作为对象空间高光法线，并与主光半角向量计算 `N·H`；结果使大范围发片同时出现块状高光，未形成天使环。
- 直接高光试验的 Shader 分支、Inspector 开关和测试材质关键词已撤回；材质恢复为关闭主高光的试验前状态。
- 现阶段只确认 RGB 是近单位方向编码，不能据此断言其高光语义；后续需以原版动态参照收敛机制。
- Unity 自动重新导入 Shader 与自定义材质 Inspector；检查本次相关日志未发现 Shader 或 C# 编译错误。
- FBX 对照：以 `CH0221_Body` 的 Hair 槽位（材质索引 `4`）取顶点法线，贴图方向与对象空间法线的最佳轴变换平均点积仅 `0.263`，排除“网格法线的坐标变体”。此结论不排除人为绘制的高光方向场。
- 资源绑定审计：原始与测试头发材质把 Hair Spec 保存到遗留 `_SpecGlossMap`，而 GTS 读取 `_SpecularMap`；后者当前为空，场景未在采样这张图。
- 切线空间 TBN 试验在场景中劣于上一版对象空间结果，已回退；当前恢复对象空间方向场版本。后脑勺与发簇问题暂不通过切换空间硬修，后续先分析发簇分区与方向场连续性。
- 新增对象空间光照方向对照试验：方向场不再与半角方向匹配，而是直接与主光方向匹配，用于判断后脑勺与发簇错误是否由视线项造成。
- Alpha 反向对照效果不如未反转版本，已回退到 `saturate(A * 2)`；保留对象空间主光方向版本作为当前基线。
- Alpha 硬排除试验已撤回，恢复 `saturate(A * 2)` 的连续 Alpha 响应权重和对象空间主光方向基线。
- 按用户确认尝试方向 2：将 Hair Spec RGB 投影到真实表面法线切平面作为发簇切线，使用 Kajiya–Kay 风格各向异性高光；新增各向异性指数参数，初始值为 `16`。
- 将当前各向异性切线场版本正式命名为 `S 方案`并记录参数，作为后续回退基线；开始尝试方案 3（模型空间反射方向 + 环境反射采样）。
- 方案 3 环境反射方向试验效果不符合预期，已完整回退到 S 方案：投影方向到法线切平面、Kajiya–Kay 各向异性指数 `16`、Alpha 响应权重 `0.5`。
- 在不改变 S 方案默认效果的前提下增加三个调节项：贴图切线混合、高光带方向偏移、Alpha 响应曲线，用于处理发簇方向、光带侧向和 Alpha 对比问题。
- Unity 导入 Shader 与自定义 Inspector 后未出现 `Shader error` 或 `error CS`；日志仍有既存的 `All subshaders removed` 导入警告，需在场景观察时确认不会影响目标材质。
