# BehaviorEditor 播放器纯 C# 化

- `BehaviorExecutor` 移除 `MonoBehaviour` 继承与 Inspector 调试字段，改为构造时绑定行为宿主 `GameObject` 的纯 C# 播放会话。
- 外部状态、能力或宿主组件负责在自身生命周期内调用 `Play`、`Tick(deltaTime)`、`Stop`，使暂停、打断、逐帧重放与驱动时机由上层决定。
- 轨道 Gizmo 分发保留为 `DrawGizmos()`，由外部 `MonoBehaviour.OnDrawGizmosSelected()` 按需调用。

## HSM 中断容器方案

- 完成 HSM 中断容器解耦重构方案文档：状态实例按实体独立持久化；状态图由实体 HSM 初始化阶段集中组装；当前状态每帧完整评估中断规则并按最大优先级选择唯一转换；同优先级使用注入顺序稳定裁决。
- 按最终 API 收紧为唯一的 `To(target, interrupt, priority)`：父类强制子类实现 `Interrupt()`，组装器可接收状态实例、外部实例、静态方法或闭包提供的 `Func<bool>`；HSM 不区分中断方法来源，条件只读无副作用，目标状态在 `OnEnter()` 中消费自己的输入或请求。
- BetterHSM 生命周期改为无 `deltaTime` 的 `OnInitialize`、`OnEnter`、`OnUpdate`、`OnExit`、`OnDispose`，由实体的 `Update()` 驱动 `BetterHSM.Update()`。
- 破坏式重构已落地到 `Core/Gameplay/BetterHSM` 六个纯 C# 文件；旧非泛型 HSM、`Tick` 和 `OnTick(float)` 链路未保留兼容层。
- 新增 `Test/HSM/HSMUsageExample.cs`，用 `HSMUsageExample` 展示实体上下文、状态实例、角色专属状态图注册、实例抽象 `Interrupt()` 和 `Update/Dispose` 驱动方式。
- 2026-09-08：建立 BetterHSM 接入 GAS 的顶层骨架；`BetterHSMAbilitySO` 先按 `Character`、`Enemy`、`NPC` 分类选择状态图方案，具体二级状态图工厂待角色设计确定后显式写入静态目录。
