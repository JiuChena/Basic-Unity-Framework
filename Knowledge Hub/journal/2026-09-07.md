# BehaviorEditor 播放器纯 C# 化

- `BehaviorExecutor` 移除 `MonoBehaviour` 继承与 Inspector 调试字段，改为构造时绑定行为宿主 `GameObject` 的纯 C# 播放会话。
- 外部状态、能力或宿主组件负责在自身生命周期内调用 `Play`、`Tick(deltaTime)`、`Stop`，使暂停、打断、逐帧重放与驱动时机由上层决定。
- 轨道 Gizmo 分发保留为 `DrawGizmos()`，由外部 `MonoBehaviour.OnDrawGizmosSelected()` 按需调用。

## HSM 中断容器方案

- 完成 HSM 中断容器解耦重构方案文档：状态实例按实体独立持久化；状态图由实体 HSM 初始化阶段集中组装；当前状态每帧完整评估中断规则并按最大优先级选择唯一转换；同优先级使用注入顺序稳定裁决。
- 按最终 API 收紧为目标状态静态 `CanEnter(TContext)`：条件只读无副作用，目标状态在 `OnEnter()` 中消费自己的输入或请求；移除 `IStateInterrupt` 与 `OnAccepted` 设计。
- HSM 生命周期改为无 `deltaTime` 的 `OnInitialize`、`OnEnter`、`OnUpdate`、`OnExit`、`OnDispose`，由实体的 `Update()` 驱动 `HSM.Update()`。
- 破坏式重构已落地到 `Core/Gameplay/HSM` 六个纯 C# 文件；旧非泛型 HSM、`Tick` 和 `OnTick(float)` 链路未保留兼容层。
