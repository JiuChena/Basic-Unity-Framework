# 2026-08-04 UnitMover 策略层级重构

## 生命周期容器重构补记

- 新增 `UnitMoverLifecycleContainer`：由每个 `UnitMover` 独占，按注册顺序保存并调用策略提供的 `Action` 回调，支持运行时帧上下文和 Gizmo 上下文读取。
- `UnitMovementStrategy` 保留首次 `OnInitialized()` 与显式 `ClearState()`，新增 `OnRegisterLifecycle()`；移除旧 `OnActivated`、`Simulate`、`OnDeactivated`、`OnDispose`、`OnRuntimeDependenciesChanged` 及策略级 Authoring 入口。
- `NormalGroundMovementStrategy` 和 `BasicMovementTestStrategy` 已迁移为无参回调注册；默认策略仍在自己的固定步包装方法中完成模块编排与唯一一次 `Body.Commit`。
- `UnitMover` 的策略切换统一执行“旧策略 Deactivated -> 容器 Clear -> 目标策略重新注册”；首次创建的策略额外执行 `Initialize`，已缓存策略保留状态但重新注入回调。
- 编辑模式的胶囊同步、基础形状恢复、基础形状重捕获和 Scene Gizmo 同样经由容器的 Authoring / Gizmo 阶段完成；`UnitMoverEditor` 替换初始策略前改为调用 `RestoreInitialStrategyAuthoring()`。

- 确认不采用 ScriptableObject 配置，也不引入万能 `IUnitMovementContext`；策略以 `[SerializeReference]` 直接持有各自的可序列化配置与模块。
- 将 `UnitMover` 收紧为 Unity 引用解析、`IUnitBody` / `IPhysicsQuery` 创建、策略缓存与生命周期管理器。它不读取 Blackboard，也不再承担固定步模块编排。
- 删除 `UnitMovementRuntime`、`UnitMovementProfile`、`IUnitMovementCommandSource` 和旧命令来源注册表；删除相应 `.meta`。
- 用 `NormalGroundMovementStrategy` 替换 `DefaultRigidbodyMovementStrategy`，并使用 `MovedFrom` 保留 Unity 序列化类型迁移路径。
- 将旧 Runtime 的固定步流程迁入默认策略；默认策略缓存 `IUnitMovementInput` 与可选 `IUnitMovementReferenceFrame`，自主管理 Jump、Gravity、Hover、SteepSlope 与 EdgeProtection 的调用顺序。
- `UnitMoverEditor` 改为自动显示策略一级序列化字段，保留深色全宽折叠栏、浮动胶囊底部留空动态上限、运行时诊断和 Gizmo 开关。
- 策略一级配置字段可用 `[UnitMovementModuleName("中文标题")]` 定义 Inspector 模块标题；Editor 使用字段名和完整序列化路径双通道反查特性，并将结果同步用于模块外层标题与内层折叠栏，无需为新策略增加专用 Editor 分支。
- 修复策略切换的共享碰撞体泄漏：`ColliderShapeModule` 可恢复浮动前胶囊快照并仅回收自身脚底盒；首次创建目标策略前，`UnitMover` 先停用旧策略。Inspector 替换初始策略也会通过通用 `RestoreAuthoring(...)` 钩子完成相同清理。
- 修复播放模式 Inspector 策略选择只改 SerializeReference、未切换活动实例的问题：新增 `UseMovementStrategy(Type)`，播放中的下拉框改为调用该入口，确保旧策略的停用恢复与新策略激活真实执行。
